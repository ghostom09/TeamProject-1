# EndlesS

> 2D Platformer Action Survival Game

**EndlesS**는 자신만의 무기로 끝없이 몰려오는 적들을 처치하며,
증강과 스탯을 성장시켜 최대한 오래 생존하는 **2D 플랫포머 액션 생존 게임**입니다.

플레이어는 전투를 통해 경험치를 획득하고, 레벨업 시 증강을 선택하여 자신만의 빌드를 완성합니다.
시간이 지날수록 적의 수와 난이도가 증가하며, 다양한 스킬과 궁극기를 활용해 생존하는 것이 핵심입니다.

## 트러블 슈팅

### 1. 오브젝트 풀링 후 애니메이션 상태가 꼬이는 문제

#### 문제

오브젝트 풀링을 적용한 공격 오브젝트가 다시 활성화될 때,
이전 애니메이션 상태가 남아 있어 애니메이션이 정상적으로 재생되지 않는 문제가 발생했습니다.

#### 원인

오브젝트가 파괴되지 않고 재사용되기 때문에,
비활성화 이전의 Animator 상태가 초기화되지 않은 채 다시 활성화되었습니다.

#### 해결

오브젝트가 다시 활성화될 때 Animator를 강제로 초기화하고,
필요한 애니메이션을 처음 상태부터 재생하도록 처리했습니다.

#### 결과

오브젝트 풀링을 유지하면서도 애니메이션이 꼬이지 않고 정상적으로 재생되도록 개선했습니다.

---

### 2. Raycast 판정과 벽 판정이 충돌하는 문제

#### 문제

총알 판정을 Raycast로 처리하는 과정에서,
실제로는 적에게 맞지 않아야 하는 상황인데 벽 판정이 감지되어 공격이 통하는 문제가 발생했습니다.

#### 원인

Raycast는 선 형태로 판정하기 때문에,
오브젝트의 두께와 위치에 따라 의도와 다르게 벽을 감지하지 않는 경우가 있었습니다.

#### 해결

단순 Raycast 대신 원형 범위 판정을 활용하여,
충돌 지점 주변에서 가장 먼저 닿는 대상에게 데미지를 적용하도록 수정했습니다.

#### 결과

적이 공격 범위 밖에 있음에도 벽 판정 때문에 데미지가 들어가는 문제를 줄였습니다.
